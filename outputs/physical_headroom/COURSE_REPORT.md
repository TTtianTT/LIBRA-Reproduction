# LIBRA 仿真扩展：PPO 结果可由固定偏移解释

## 核心发现

**PPO 没有展示额外的状态相关控制。** 15/15 个高预算随机初始化选中结果，在费用、违约数、VM 秒、FaaS 请求和启动 VM 秒上都与某个固定残差动作相同。
固定残差仍会随负载规则调整 VM，固定的是规则上的偏移和路由。补上这项廉价网格对照后，原来‘追平教师’的结论不再构成学习收益。

原始增量动作则会累加：旧失败种子的 2788/2880 步选择 +4 台，最终反复到达 512 台上限。

| 旧模型场景 | 教师费用 $ | 训练集选出的固定动作费用 $ | PPO 高预算平均费用 $ |
|---|---:|---:|---:|
| v1 | 24.794 | 24.794 | 24.794 |
| v2_s05 | 16.361 | 15.803 | 16.592 |
| v2_s07 | 24.584 | 23.319 | 23.414 |

这张旧表只用于算法审计，不再作为物理 SLA 证据。原 85 次 8k–16k 步训练保留为早期探索记录。

**旧排队模型高估固定服务时间下的延迟。** 现已改为每台 VM 16 槽位的 FCFS 事件队列，保留跨秒积压，并对缩容及回合末排空计费；满载不再直接判整秒违约。M/D/16 经验查表只用于稳态校准。

**修正后，基线仍比扩大 PPO 训练更值得先做。** 0.7s 场景的因果经济分位数规则，比最佳固定残差便宜 29.53%；完美分位数预测只再便宜 1.49%。所有候选参数在训练集选，结果如下。

| 服务时间 | 对照 | 两个验证小时的费用 $ | 违约率 % |
|---:|---|---:|---:|
| 0.5 | 最佳固定残差 | 0.241595 | 0.00177 |
| 0.5 | 因果经济分位数规则 | 0.243262 | 0.00177 |
| 0.5 | 完美分位数预测规则 | 0.244121 | 0.00177 |
| 0.5 | 已证最优的全未来计划 | 0.223930 | 0.00809 |
| 0.7 | 最佳固定残差 | 0.480032 | 0.00910 |
| 0.7 | 因果经济分位数规则 | 0.338294 | 0.02529 |
| 0.7 | 完美分位数预测规则 | 0.333255 | 0.04172 |
| 0.7 | 已证最优的全未来计划 | 0.289880 | 0.09861 |

数据为 Azure 分区内 16 个非循环错峰副本，训练日 1–9、开发验证日 10–11；训练和验证均有过去 1,800s 历史，只读已完成秒。表中均值来自同两个独立 1h 冷启动回合的五个到达/路由随机种子；每回合分别约束违约率 ≤0.1%。

## 不能从 DP 差距推导 RL 收益

20/20 个预设服务时间/到达种子/窗口组合均已得到最优性证书：无 beam 剪枝的队列状态搜索，加上 SLA 松弛 DP 下界，使上下界在数值容差内闭合。这个最优值只针对本次有限动作域和指定到达样本。
全未来搜索还知道未来到达与路由随机数；完美分位数规则只是一种启发式。两者的差距混合信息、规划和算法误差，不能直接解释成在线 RL 可学到的序贯收益。0.5s 的完美预测规则反而略贵，也说明这一点。

以训练集选出的最强因果规则为参照，全未来最优的费用改善上限为 7.31%（0.5s）和 14.31%（0.7s）；在线策略只能争取其中可预测、可控制的部分。

## 结论

本轮纠正了基线遗漏和物理模型，没有继续 PPO。下一步应先冻结强因果预测基线并取得独立评估数据；若仍有可学空间，再使用输入驱动 baseline、16 个并行环境和至少 100 万步训练。验收必须同时看非恒定有效动作、费用和 SLA。
